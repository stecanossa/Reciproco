# **Welcome to Reciproco!**


This program contains various interactive tools for the use of of single-crystal diffraction data for total scattering research.

Its graphical user interface aims at providing an intuitive user experience and the freedom to adopt fully automated or user-controlled workflows to go from raw diffraction images to reciprocal space reconstructions, diffuse scattering volumes, 3D-deltaPDF maps, and much more.

(The program is approaching its final stages of development, and everyone will hopefully have their chance to try it out soon)
