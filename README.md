# **Welcome to Reciproco!**


This program contains various interactive tools for the use of of single-crystal diffraction data for total scattering research.
Its name stands for "Reciprocal space Processing and Conversion", and its graphical user interface aims at providing an intuitive user experience to conduct automated or user-controlled workflows that lead from raw diffraction images to reciprocal space reconstructions, diffuse scattering volumes, 3D-delta-PDF maps, and much more.

The program is approaching its final stages of development, and everyone will hopefully have their chance to try it out soon. Stay tuned ;)
